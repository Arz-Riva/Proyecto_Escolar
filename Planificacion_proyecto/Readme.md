# Explicación General del Proyecto 

Este programa será un encargado de calcular tablas de amortización y mostrarlas al usuario de forma interactiva, segun los datos que ingrese y con eso el usuario podra tener una idea de cuanto tiene que pagar y cuando tiene que pagar, segun el sistema de amortización que elija, con ayua de graficas de los datos calculados, y con esto tener una idea clara de como se comporta el préstamo en el tiempo.
