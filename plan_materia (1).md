| Nivel de dominio | Descripción del nivel | Equivalencia numérica |

| **Sobresaliente** | El o la estudiante demuestra dominio total de los fundamentos del paradigma de programación funcional. Es capaz de utilizar de manera eficiente los entornos de desarrollo y de resolver problemas de manera computacional aplicando el paradigma funcional con el lenguaje de programación Python. Hace uso de buenas prácticas y tiene capacidad para corregir errores tanto de lógica como de sintaxis. | 9.5 a 10 |
| **Competente** | El o la estudiante demuestra conocimiento de algunos fundamentos del paradigma de programación funcional. Es capaz de utilizar algunas de las características de los entornos de desarrollo y de resolver solo algunos problemas de manera computacional aplicando el paradigma funcional con el lenguaje de programación Python. Hace uso de solo algunas buenas prácticas y tiene capacidad para corregir solo algunos errores tanto de lógica como de sintaxis. | 8.0 a 9.4 |
| **Suficiente** | El o la estudiante demuestra poco conocimiento de los fundamentos del paradigma de programación funcional. Es capaz de utilizar muy pocas características de los entornos de desarrollo y de resolver pocos problemas de manera computacional aplicando el paradigma funcional con el lenguaje de programación Python. Casi no utiliza las buenas prácticas y tiene poca capacidad para corregir errores de lógica y de sintaxis. | 6.0 a 7.9 |
| **No competente** | El o la estudiante no demuestra conocimiento de los fundamentos del paradigma de programación funcional. No es capaz de utilizar las características de los entornos de desarrollo, ni de resolver problemas de manera computacional aplicando el paradigma con el lenguaje de programación Python. No utiliza buenas prácticas y no tienen capacidad para corregir errores de lógica y de sintaxis. | Menor a 6.0 |

### Unidad I: Fundamentos del paradigma de programación Funcional

- **Período de desarrollo:** 17/08/2026 - 14/09/2026
- **Resultados de aprendizaje:** Conocer, aprender y aplicar el paradigma de programación funcional con Python para el uso efectivo del lenguaje mediante buenas prácticas.

#### Contenidos a desarrollar
- **1.1 Introducción a la Programación Funcional**
  - 1.1.1 ¿Qué es la programación funcional?
  - 1.1.2 Paradigma de programación
  - 1.1.4 Funciones matemáticas
  - 1.1.5 Cambios de estado
  - 1.1.6 POO vs PF
- **1.2 Comparación de paradigmas de programación con Python**
  - 1.2.1 Ejemplo de Programación estructurada
  - 1.2.2 Ejemplo de Programación orientada a objetos
  - 1.2.3 Ejemplos de Programación funcional
- **1.3 Conceptos de Python para la aplicación del paradigma funcional**
  - 1.3.1 Estructura de los programas con Python
  - 1.3.2 Tipos de datos
    - 1.3.2.1 Numéricos: int, float, complejo, decimal, científico
    - 1.3.2.2 Lógicos: bool
    - 1.3.2.3 Cadena: string
  - 1.3.3 Operadores
    - 1.3.3.1 Aritméticos
    - 1.3.3.2 Lógicos
    - 1.3.3.3 Condicionales
      - 1.3.3.3.1 Expresiones condicionales (operador ternario)
  - 1.3.4 Estructuras de datos
    - 1.3.4.1 Listas (list)
    - 1.3.4.2 Diccionarios (dict)
    - 1.3.4.3 Conjuntos (set)
    - 1.3.4.4 Tuplas (tuple)
  - 1.3.5 Estructuras condicionales
    - 1.3.5.1 if
    - 1.3.5.2 if-else
    - 1.3.5.3 if-elif-...-else
    - 1.3.5.4 Concordancia de patrones estructurado (structural pattern matching)
  - 1.3.6 Estructuras para control de flujo
    - 1.3.6.1 Iterables e Iteradores
    - 1.3.6.2 Estructura for
    - 1.3.6.3 Estructura while
    - 1.3.6.4 Uso de range, break y continue
    - 1.3.6.5 Estructuras anidadas

### Unidad III: Programación con lenguajes funcionales

- **Período de desarrollo:** 02/10/2026 - 26/11/2026
- **Resultados de aprendizaje:** Conocer, aprender y aplicar los fundamentos básicos del paradigma de programación funcional mediante la solución de problemas de manera computacional utilizando el lenguaje de programación Python.

#### Contenidos a desarrollar
- **3. Programación con lenguajes funcionales**
  - **3.1 Funciones de alto orden**
    - 3.1.1 `max()` y `min()`
    - 3.1.2 `map()`
    - 3.1.3 `filter()`
    - 3.1.4 `reduce()`
    - 3.1.5 `zip()`
    - 3.1.6 `iter()`
    - 3.1.7 `sorted()`
  - **3.2 Decoradores**
    - 3.2.1 Introducción a los Decoradores
    - 3.2.2 Creación de Decoradores
    - 3.2.3 Aplicación de decoradores a funciones
    - 3.2.4 Decoradores Predefinidos
      - 3.2.4.1 Uso de `@staticmethod` y `@classmethod`
      - 3.2.4.2 Decoradores para propiedades (`@property` y `@setter`)
      - 3.2.4.3 Decoradores para el manejo de excepciones (`@try_except`)
  - **3.3 Generadores**
    - 3.3.1 Creación de Generadores
    - 3.3.2 Función `yield`
    - 3.3.3 Secuencias con generadores
    - 3.3.4 Generadores finitos e infinitos
    - 3.3.5 Uso Eficiente de Generadores
      - 3.3.5.1 Aplicación en el procesamiento de archivos grandes
      - 3.3.5.2 Generación de números primos y secuencias especiales
      - 3.3.5.3 Implementación de generadores de Fibonacci y rangos personalizados
  - **3.4 Módulo operador (`operator`)**
    - 3.4.1 Introducción
    - 3.4.2 Funciones Aritméticas: `add`, `sub`, `mul`, `truediv`, `floordiv`, etc.
    - 3.4.3 Funciones de Comparación: `lt`, `le`, `eq`, `ne`, `gt`, `ge`
    - 3.4.4 Funciones de Operaciones Lógicas: `and_`, `or_`, `not_`
    - 3.4.5 Funciones para Operaciones de manipulación de estructuras de datos: `getitem`, `setitem`, `delitem`, `contains`, etc.
